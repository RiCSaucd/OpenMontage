# How Neural Networks Learn

60-second 1920×1080 teacher-explainer. Pipeline: `animated-explainer`.

Locked concept: **Guess, number, nudge** — a network does not memorize; it guesses, scores the miss as a number, and walks that error backward so every weight can move a little.

This Cloud VM locks **ffmpeg** (Remotion, HyperFrames, and Piper are unavailable). Captions are the voice. Bed is a procedural sine pulse. Cost $0.

```
.venv/bin/python scripts/produce_how_neural_networks_learn.py
```

Output: `projects/how-neural-networks-learn/renders/how-neural-networks-learn.mp4`
