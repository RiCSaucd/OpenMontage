# Scene Director — Nexus True Crime Short

## When to Use

Map the approved script to a shot / slot plan favoring archival and period texture.

## Prerequisites

- `script`, `proposal_packet`
- Schema: `schemas/artifacts/scene_plan.schema.json`

## Process

1. One scene slot per script beat (plus optional cold open / end card).
2. Prefer archival stills, newsreels, maps, documents, period street texture.
3. Ban cinematic blood / hero-weapon framing from the shot list.
4. Attach VO layover windows and caption needs per slot.
5. Note where AI atmospheric B-roll is a last resort vs archival search.
6. Write schema-valid `scene_plan`. Checkpoint (approval default false).
