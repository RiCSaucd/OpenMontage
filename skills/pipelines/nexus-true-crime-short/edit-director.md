# Edit Director — Nexus True Crime Short

## When to Use

Turn assets + script into cut decisions with clear VO layover windows.

## Prerequisites

- `asset_manifest`, `scene_plan`, `script`
- Schema: `schemas/artifacts/edit_decisions.schema.json`

## Process

1. Pace for comprehension, not hype — hold archival frames long enough to read.
2. Mark VO layover windows and caption/lower-third restraint.
3. Keep music under VO; ducking notes for final user VO mix.
4. No cut that reframes violence as spectacle.
5. Write schema-valid `edit_decisions`. Checkpoint.
