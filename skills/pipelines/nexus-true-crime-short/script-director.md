# Script Director — Nexus True Crime Short

## When to Use

After proposal approval. Write a measured Shorts script with VO timing cues.

## Prerequisites

- Approved `proposal_packet`, `research_brief`
- Brand skills
- Schema: `schemas/artifacts/script.schema.json`

## Process

1. One thesis, two support beats, one consequence / context landing.
2. Open with a concrete historical hook (date, place, documented event).
3. Map every factual claim to research citations; label myths as myths.
4. Add **timing cues** (approx seconds per beat) for user-recorded VO.
5. No blood porn, hero-weapon framing, or celebratory crime lifestyle language.
6. Optional scratch TTS for length check only — not the master.
7. Write schema-valid `script`. Checkpoint → **human approval**.

## Length guide

~2.5 words/sec spoken English as a ceiling for Shorts; prefer fewer words with breathing room for archival holds.
